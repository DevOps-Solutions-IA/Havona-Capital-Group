# DIRECTRIZ VISUAL Y FUNCIONAL — HAVONA CAPITAL

## Identidad

HAVONA CAPITAL debe verse como una empresa multinacional de consultoría patrimonial, tecnología financiera y protección empresarial.

La experiencia debe ser:

- Moderna.
- Editorial.
- Minimalista.
- Premium.
- Corporativa.
- Tecnológica.
- Clara.
- Confiable.

## Paleta

- Azul profundo: `#071A33`
- Azul corporativo: `#0A3D73`
- Azul tecnológico: `#1478D4`
- Azul hielo: `#EAF4FF`
- Fondo principal: `#F3F6FA`
- Blanco: `#FFFFFF`
- Gris texto: `#667085`
- Gris oscuro: `#1D2939`
- Dorado champagne: `#C9A86A`

El dorado se usa de manera limitada.

## Tipografía

- Inter para cuerpo.
- Outfit para títulos y marca.

## Estilo

Usar:

- Fondo claro.
- Navegación flotante.
- Glassmorphism moderado.
- Bordes suaves.
- Tarjetas blancas.
- Sombras delicadas.
- Radios entre 14 y 24 px.
- Espacios amplios.
- Iconografía lineal.
- Animaciones discretas.
- Composición asimétrica.
- Contenido visual premium.

Evitar:

- Neón.
- Fondos oscuros predominantes.
- Saturación visual.
- Plantillas genéricas.
- Botones sin función.
- Datos falsos.
- Elementos decorativos sin propósito.

## Navegación pública

- Logo.
- Soluciones.
- Personas.
- Empresas.
- Recursos.
- Consultores.
- Contacto.
- Ingresar.
- Agenda una consultoría.
